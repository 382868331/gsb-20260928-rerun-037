# 基因变异证据汇总（研究流程）

这是一个仅用于研究流程的 Python 基础框架。它接收人工参考序列、已比对读段和独立 JSON 清单，输出替换与短缺口候选的支持、反对、低质量、方向偏差及覆盖证据。输出不用于诊断、治疗或任何医疗决策。

## 输入

- FASTA 人工参考序列（当前版本要求一个序列）。
- SAM 格式的已比对读段；未比对、非主比对、补充比对和重复读段按参数过滤。
- JSON 清单保存样本 ID、参考名称/版本、输入路径和分析参数，避免把这些信息写进临时脚本。

变异身份采用稳定的 `染色体:1-based位置:REF>ALT` 形式，后续注释模块可直接沿用。

## 运行

```bash
python -m variant_pipeline.cli examples/manifest.json --json-out results/variants.json --csv-out results/variants.csv
```

## 证据规则

- 重叠配对读段按相同模板 ID 聚合，不按读段出现次数直接决定变异。
- 支持证据单独统计正/反方向模板和平均碱基质量。
- 反对证据区分参考等位、其他变异等位和同一模板内冲突。
- 低于碱基/比对质量阈值的位置单独计数，不计入高质量支持。
- 方向偏差使用 Fisher 精确检验并参与可信度评分；覆盖不足会在 `coverage_note` 中单独说明并进入复核状态。

评分为研究用启发式综合分，不是临床概率或致病性证据。
